# ROX PRODUCTION

### Painel de Gestão Audiovisual

## Sobre o projeto

O ROX PRODUCTION é um sistema desenvolvido para auxiliar na organização e no gerenciamento das atividades de uma empresa do ramo audiovisual.

O projeto apresenta um painel administrativo com uma interface moderna e intuitiva, reunindo informações importantes para facilitar o acompanhamento dos serviços e a organização interna da empresa.

## Páginas do sistema

- **Dashboard:** painel principal com uma visão geral das atividades.
- **Clientes:** gerenciamento de informações dos clientes.
- **Produção:** acompanhamento dos serviços e produções audiovisuais.
- **Agenda:** organização de compromissos e atividades.
- **Softwares:** controle dos programas utilizados na empresa.
- **Financeiro:** acompanhamento financeiro, contas a pagar e receber.
- **Entregas:** controle dos materiais enviados aos clientes.

## Tecnologias utilizadas

- HTML5
- CSS3
- Visual Studio Code

## Objetivo do projeto

Aplicar na prática os conhecimentos adquiridos em desenvolvimento web, utilizando HTML5 para estruturar as páginas e CSS3 para desenvolver a identidade visual e a organização dos elementos.
